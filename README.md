# macchanger_improved
this is an improved version of mac changer . I have made this in python and this code will make any mac address of linux os into the desired one. you can choose a mac address or you can let the code set a random mac address for you.
just type : 
python macchanger.py
and then choose which interface you wanna change
then  choose the mac address (is it will be random or you will choose one)
